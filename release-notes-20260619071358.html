Orch 0.2.6 dogfood

  • Main macOS app is leaner: heavy Voice and LocalLLM resources are externalized from the default bundle.
  • Local model packs can be installed through typed app/control-plane paths instead of hidden bundled runtime assumptions.
  • Release CI now has path-scoped detection and a trusted publish gate to reduce wasted Actions time.
  • Release artifacts include bundle contract, cache, provenance, Sparkle signature, and timing evidence.
