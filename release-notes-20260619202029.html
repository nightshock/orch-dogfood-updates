Что нового в Orch 0.2.10

Этот dogfood-релиз делает историю задач устойчивее и возвращает старые треды после обновления.

  • Треды больше не зависят от короткого снимка. Orch сохраняет задачи в устойчивом локальном хранилище, поэтому новый короткий список не затирает старую историю.
  • Старые задачи возвращаются автоматически. При первом запуске после обновления Orch собирает доступные резервные копии и переносит найденные задачи в новое хранилище.
  • Удаление стало явным действием. Обычное сохранение больше не удаляет задачи, которых нет в текущем кратком списке; удаление происходит только по явному действию.
  • Диагностика смотрит на новый источник. Локальные проверки и диагностика теперь считают задачи из того же хранилища, которое использует приложение.
