Что нового в Orch 0.3.2

Orch расширяет выбор доступных моделей для чата, увереннее запускает параллельные задачи и точнее собирает рабочий контекст.

  • Больше моделей для задач. Выбирайте доступные для чата модели из подключённых сервисов.
  • Параллельные задачи меньше мешают друг другу. Долгие обновления рабочего контекста меньше задерживают запуск и управление другими задачами.
  • Рабочий контекст точнее учитывает изменения. Рабочий контекст точнее учитывает актуальные изменения проекта и сохраняет понятную связь с исходными файлами.
  • Старые задачи открываются надёжнее. Старые задачи без рабочей группы корректно открываются после обновления, а после перезапуска Orch показывает подтверждённый результат завершённых задач.
